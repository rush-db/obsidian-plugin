'rushdb-obsidian-plugin': minor

Requires Obsidian 1.13 or later (breaking for older versions). The settings tab moves to Obsidian's declarative settings, so every RushDB setting shows up in the settings search, and the API key and engine token are kept in Obsidian's secret storage instead of the plugin's data file; keys saved by earlier versions are moved there on first load.
