Setup needs fewer steps: the API key is stored under the secret `rushdb-api-default` (and the engine token under `rushdb-engine-default`) unless you pick another one, and a new install indexes the whole vault (`/`) once RushDB is connected. Saved settings are kept as they are. The related-notes sidebar now uses the RushDB logo, has a refresh button on each section that reloads just that section, shows how similar each similar note is (`0.98`), and lists notes with the most tags in common first, with a `×N` badge whose tooltip names the shared tags.
